# Бот в группах Telegram + темы (topics)

## Почему «не работает в группе»

По умолчанию у Telegram-ботов включён **режим приватности (Privacy Mode)**:
в группах бот **не видит обычные сообщения** — только команды (`/...`),
адресованные ему. Поэтому если просто кинуть в группу ссылку на поиск,
бот её **не получит**. Проверить: у `getMe` поле
`can_read_all_group_messages: false` = приватность включена.

Есть два пути — выберите любой.

---

## Путь A (рекомендуется): выключить приватность → работают обычные ссылки

Делает **владелец бота** один раз в [@BotFather](https://t.me/BotFather):

1. `/mybots` → выберите вашего бота → **Bot Settings** → **Group Privacy** →
   **Turn off**. (Или команда `/setprivacy` → выбрать бота → **Disable**.)
2. **Важно:** после смены приватности **удалите и заново добавьте** бота в
   группу — настройка применяется при вступлении.

Теперь бот видит все сообщения и реагирует на ссылки Vinted, отправленные в чат.

---

## Путь B: не трогать приватность → добавлять командой

Команды бот получает всегда, даже с включённой приватностью. Просто пишите:

```
/search https://www.vinted.de/catalog?search_text=nike&order=newest_first
```

(`/track` — синоним.) Одиночное объявление: `/parse_link <ссылка>`.

---

## Темы (topics): отдельная подтема под каждый поиск

1. В настройках группы включите **«Темы» (Topics)** — группа станет форумом.
2. Сделайте бота **администратором** и включите право
   **«Управление темами» (Manage Topics)**.
3. Добавьте поиск (ссылкой или `/search`). Бот создаст подтему
   «Vinted · Поиск: …» и будет складывать туда свежие и новые объявления 🧵.

Если Темы выключены или нет прав — бот просто пишет в общий чат.

---

## Быстрый чек-лист

- [ ] Бот добавлен в группу
- [ ] Бот — администратор с правом **Manage Topics** (для тем)
- [ ] В группе включены **Topics** (для тем)
- [ ] Приватность **выключена** (Путь A) — или используете `/search` (Путь B)
- [ ] Отправлен поиск → пришли 3 свежих + создана подписка

Внутри группы наберите **/setup** — бот пришлёт эту инструкцию.

---

## Частые проблемы

| Симптом | Причина | Решение |
|---|---|---|
| Кидаю ссылку — тишина | включена приватность | Путь A, либо `/search ссылка` |
| «Не смог создать тему» | нет права Manage Topics | дать право админа |
| Темы не создаются | в группе выключены Topics | включить Topics в настройках |
| Бот вообще не отвечает | не добавлен / кикнут | добавить бота в группу |
